# 库帕思语匠 × 书生·端砚合作 Demo

[在线体验科研题目验证](https://fengxingnuyan.github.io/yujiang-duanyan-demo/)

语匠跳转的默认落点为「我的题目」。任务名称、编号、发布方、截止日期和专家身份采用示例信息。专家可在同一项科研 RSI 任务下创建多道题。列表展示每道题的状态、轮次和建议回访日期，需修改的题目排在最前。

新建题目后，填写名称、领域并添加附件，或点击「填入示例材料」。开始填写即保存草稿，草稿可从列表的「更多」中删除。首次提交后不能撤回或删除。预审、运行、评审分别按每道题的提交时间推进，回访日期为提交后的下一个自然日。

页尾「演示设置」可以选择全流程通过、题目预审需修改或题目评审需修改。需修改时，报告上方提供「修改题目与附件」按钮，滚动长报告时仍可使用。重新提交后可展开历史轮次查看报告。

同一浏览器再次访问可恢复各题进度，旧版单题记录会自动迁入列表。每个模拟阶段约 4.5 秒。附件仅在本机保留名称和大小。登录、运行与评审均为演示，正式 SSO、科研执行和平台间接口待接入。

下载仓库后，在仓库目录中使用浏览器打开 index.html 即可体验。
