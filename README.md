# 库帕思语匠 × 书生·端砚合作 Demo

专家题目验证、后台自动运行与产物评审流程的交互原型，基于 Demo V6。

## 如何查看

下载本仓库后，直接用浏览器打开 `index.html`。无需安装依赖或启动后端。

## 专家操作路径

1. 阅读合作介绍，进入信息收集页。
2. 填写团队、联系人和研究标题，添加题目附件；也可点击“填入示例材料”。
3. 提交题目验证，查看题目评审智能体的模拟反馈。
4. 验证通过后自动进入后台任务运行，生成本轮产物。
5. 下载产物 ZIP，主动点击“提交产物评审”。
6. 查看评测报告；不合格时点击“重新开始任务”，按清单修改赛题后重跑。

## 演示场景

页面底部可切换：验证与产物评审合格、产物评审不合格、需补充材料、题目评审服务异常、后台运行异常、产物评审异常。

## 原型边界

- 页面中的验证、执行、评审结果及压缩包内容均为模拟数据。
- 选择文件只记录文件名和大小，不读取或上传附件正文。
- 状态保存在当前页面内存中，刷新页面会重置；演示计时不代表正式服务时长。
- SSO、真实文件上传、后台科研任务、两个评审智能体及最终产物 API 尚未接入。
- 题目与产物两个评审智能体对应的 Skill 均由库帕思提供；端砚负责接入与展示。

本仓库用于合作流程讨论与交互演示。
