# 库帕思语匠 × 书生·端砚合作 Demo

[在线体验科研题目验证](https://fengxingnuyan.github.io/yujiang-duanyan-demo/)

任务页使用示例专家身份。填写题目名称、领域并添加附件，或点击「填入示例材料」，再点「提交题目」。题目依次进入预审、运行和评审。页面给出下一个自然日的建议回访日期，预审结束后可查看本轮预审报告，最终评审结合题目要求和运行记录给出结论。

页尾「演示设置」可以选择全流程通过、题目预审需修改或题目评审需修改。需修改时，报告上方提供「修改题目与附件」按钮，滚动长报告时仍可使用。重新提交后可展开历史轮次查看报告。

同一浏览器再次访问可恢复本次示例任务。页面根据提交时间推演阶段，每个阶段约 4.5 秒。重置演示会清除本机示例进度。附件仅在本机保留名称和大小。登录、运行与评审均为演示，正式 SSO、科研执行和平台间接口待接入。

下载仓库后，在仓库目录中使用浏览器打开 index.html 即可体验。
