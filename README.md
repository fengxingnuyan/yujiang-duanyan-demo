# 库帕思语匠 × 书生·端砚合作 Demo

[在线体验科研题目验证](https://fengxingnuyan.github.io/yujiang-duanyan-demo/)

任务页用示例身份演示从语匠跳转后看到的内容。点击「填入示例材料」，再点「提交题目」，即可体验题目预审、任务运行和产物评审三个自动阶段。提交页给出下一个自然日的建议回访日期，完成后可查看评测结论。

展开页尾的「演示设置」，可以在提交前选择预审退回、产物评审退回、模型未解出或服务异常。需修改时，按问题清单更新题目并重新提交，历史轮次可供查看。

同一浏览器再次访问可恢复本次示例任务。页面根据提交时间推演阶段，每个阶段约 4.5 秒。重置演示会清除本机示例进度。附件仅在本机保留名称和大小。登录、运行与评审均为演示，正式 SSO、科研执行和平台间接口待接入。

下载仓库后也可以将 index.html 和 demo.js 放在同一目录，使用浏览器打开 index.html。
